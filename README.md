<h3 align="center">Advanced eXecutive Disk Operating System</h3>

<p align="center">
<strong>A hobby operating system built from scratch using C and x86 Assembly.</strong>
<br>
Exploring the fundamentals of operating systems, computer architecture, and low-level programming.
</p>

<h2>About AXDOS</h2>

<p>
<strong>AXDOS (Advanced eXecutive Disk Operating System)</strong> is an experimental operating system developed from the ground up.
</p>

<p>
Unlike ordinary applications, AXDOS runs directly on computer hardware, handling its own boot process and kernel execution.
</p>

<p>
The project aims to explore how operating systems work internally, from bootloaders and processor modes to hardware interaction and kernel development.
</p>

<p>
<strong>You can try AXDOS right now without compiling anything!</strong> A precompiled operating system image is included in this repository.
</p>

<hr>

<h2>Running AXDOS</h2>

<p>
The easiest way to experience AXDOS is through
<a href="https://www.qemu.org/">QEMU</a>, an open-source machine emulator.
</p>

<ol>
<li>
<strong>Download AXDOS</strong>
<p>Download the precompiled <a href="AXDOS.bin"><code>AXDOS.bin</code></a> file from this repository.</p>
</li>
<li>
<strong>Install QEMU</strong>
<p>Download QEMU from its official website:</p>
<a href="https://www.qemu.org/download/">https://www.qemu.org/download/</a>
</li>
<li>
<strong>Boot AXDOS</strong>
<p>Open a terminal in the directory containing <code>AXDOS.bin</code> and execute:</p>
<pre><code>qemu-system-i386 -drive format=raw,file=AXDOS.bin</code></pre>
</li>
</ol>

<p>QEMU should start a virtual machine and boot directly into AXDOS.</p>
